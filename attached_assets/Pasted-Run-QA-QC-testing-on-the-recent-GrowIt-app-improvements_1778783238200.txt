QA/QC Checklist:

1. Foliage & Ornamental Plants category
Check:
- Category appears anywhere users browse/filter/select plant types.
- Category appears in Custom Selection.
- Category appears in custom plant add/edit category dropdowns.
- Category uses the display name “Foliage & Ornamental Plants.”
- Category uses the 🌿 icon where category icons are used.
- Example plants appear, such as Hostas, Ferns, Ornamental grasses, Boxwood, Juniper, Dwarf spruce, Coral bells / Heuchera, Brunnera, Bergenia, and Solomon’s seal.
- Category does not replace or rename Vegetables, Herbs, or Flowers.
- Generated garden plans can include foliage/ornamental plants.
- Garden map, plant table, weekly schedule, download, and share correctly display this category.

Test cases:
A. Custom Selection → select only Foliage & Ornamental Plants → Generate plan.
Expected: map/table/schedule show only foliage/ornamental plants.
B. Custom Selection → select Hostas and Ferns only → Generate plan.
Expected: only Hostas and Ferns appear, repeated or placed where appropriate.
C. Custom Selection → select Flowers + Foliage & Ornamental Plants.
Expected: only selected flowers and selected foliage/ornamental plants appear.

2. Custom Selection search box
Check:
- Search box only appears in Custom Selection mode.
- Search box is hidden in non-custom garden goals.
- Search box is placed between category tabs and the plant section header.
- Search input is pill-shaped.
- Search icon appears on the left.
- Placeholder reads “Search plants…”
- Clear ✕ button appears only when text is typed.
- Clear ✕ button clears the input and restores the full plant list.
- Search is case-insensitive.
- Search filters across all categories, regardless of active category tab.
- Search includes Vegetables, Herbs, Flowers, and Foliage & Ornamental Plants.
- Existing selections remain selected even if hidden by search.
- “No plants match your search.” appears when appropriate.
- “No plants in this category suit your current garden conditions” is hidden while actively searching.

Test cases:
A. Search “mar” → Marigolds appears.
B. Search “host” → Hostas appears.
C. Search “zzzzzz” → “No plants match your search.”
D. Select a plant, search for another plant, then clear search.
Expected: original selected plant remains selected.
E. Switch out of Custom Selection mode.
Expected: search bar disappears.

3. Custom Selection generation logic

- It does not generate a generic mixed garden.
- It does not auto-add vegetables, herbs, flowers, or foliage plants from unselected categories.
- It does not fill empty map spaces with unselected plants.
- Empty spaces may remain empty if there are fewer selected plants than grid cells.
- If selected plants exceed available space, app includes as many as fit and shows a friendly note if needed.

Test cases:
