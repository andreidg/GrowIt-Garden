2. Update plant selection to support both manual selection and app recommendation

We want users to have two options:
A) manually select specific plants they want in their garden, or
B) let GrowIt recommend plants for them based on their garden inputs.

Do not make manual plant selection the only path.

Add a button to each plant selection category called:
“Pick My Plants”

Plant categories should include:
- Vegetables
- Herbs
- Flowers

Button behaviour:
- Each category should have its own “Pick My Plants” button.
- When the user clicks “Pick My Plants” in a category, GrowIt should automatically recommend suitable plants from that category based on:
  - growing region
  - frost dates
  - garden area size
  - sunlight level
  - soil/container type
  - selected garden goal/type
  - available space
- The app should then select or add the recommended plants from that category.
- The user should still be able to manually add or remove plants after GrowIt recommends them.
- If a plant is not suitable for the selected conditions, do not select it automatically.
- If the available space is limited, select a smaller number of suitable plants and show a short note explaining that recommendations were limited by space or conditions.

Manual selection requirements:
- Users can still manually select individual plants.
- Users can still add a custom plant.
- Manual selections should be treated as preferences, not guaranteed placements if conditions are unsuitable.
- If a selected plant may not work well, show a warning and suggest a better alternative.

Product logic:
- GrowIt should be recommendation-first, with optional customization.
- The core value is that GrowIt recommends what to plant, where to plant it, and when to plant it.
- Manual plant selection supports customization, but should not replace the recommendation engine.
