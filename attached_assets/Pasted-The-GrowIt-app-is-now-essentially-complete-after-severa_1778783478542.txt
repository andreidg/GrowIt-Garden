11. Custom Selection generation logic
This is critical.

When Garden Goal is “Custom selection”:
- Selected plants are the source of truth.
- The app must not generate a generic mixed garden.
- The app must not auto-add unselected categories.
- The app must not fill empty grid spaces with unselected plants.
- Empty spaces may remain empty.
- If only flowers are selected, only flowers appear.
- If only foliage/ornamental plants are selected, only foliage/ornamental plants appear.
- If only one plant is selected, only that plant appears, repeated or placed where appropriate.
- If selected plants exceed available space, include what fits and show a friendly note if needed.
- If no plants are selected, ask the user to select at least one plant or choose a recommended garden goal.

B. Custom Selection → manually select only Marigolds → Generate.
Expected: only Marigolds appear.

C. Custom Selection → select Basil + Thyme + Marigolds.
Expected: only those selected plants appear.

D. Custom Selection → select only Hostas and Ferns.
Expected: only Hostas and Ferns appear.

E. Custom Selection → select nothing → Generate.
Expected: user is prompted to select at least one plant or choose a recommended goal.

F. Vegetable-focused mode → Generate without manual selection.
