# GrowIt

Location-aware, mobile-first garden planning web app for Alberta homeowners. Generates personalised planting plans with frost-date-aware schedules, companion planting logic, and a garden map — all without requiring an account.

## Run & Operate

- `pnpm --filter @workspace/api-server run dev` — run the API server (port 5000)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- Frontend: React + Vite + Tailwind v4 + shadcn/ui + wouter
- API: Express 5
- DB: PostgreSQL + Drizzle ORM
- Validation: Zod (`zod/v4`), `drizzle-zod`
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)

## Architecture decisions

- **Deterministic-first**: Every plan is generated by a local deterministic algorithm. AI enhances but never replaces it — graceful fallback on any failure.
- **Types as single source of truth**: `garden.ts` defines all interfaces; generator and UI import from it, never redeclaring shapes.
- **Backward compat via normalizeProfile()**: Old saved plans (without `areas`/`selectedPlantIds`) are migrated at generation time — no schema migration needed.
- **Sunlight scoring with tolerance**: `sunlightCompatible()` uses a score map (Full Sun=5 … Full Shade=1). Part Sun (4) can support Full Sun plants (5−1=4) — a 1-level tolerance prevents over-exclusion.
- **Per-area grids**: `areaPlans: AreaPlan[]` on `GeneratedPlan` gives each garden area its own grid and plant list. Primary area mirrors top-level fields for API backward compat.

## Product

- 3-step questionnaire: pick region → configure garden areas → select plants
- Multiple garden areas with individual sunlight, soil, and dimension settings
- 5 sunlight levels (Full Sun / Part Sun / Part Shade / Dappled Shade / Full Shade) with inline descriptions
- Plant multi-select across Vegetables, Herbs, Flowers with "select all" per category
- Custom plant entry with category tagging and scheduling caution notes
- Garden map grid per area with companion conflict highlighting
- Frost-anchored week-by-week schedule
- Photo analyzer to auto-detect sunlight/soil for primary area
- Download Plan (branded PDF via jsPDF) and Share Plan (Web Share API / clipboard fallback)
- Weather risk card from live API

## Gotchas

- Plant `minSunlight` in plants.ts uses `"Partial Shade"` (old value). The questionnaire shows the new 5-option set. `sunlightCompatible()` in plan-generator.ts handles both old and new values via the score map.
- The photo analyzer pre-fills only the **primary area** (areas[0]) sunlight and soil type.
- `areaInputs` in QuestionnairePage stores display strings per area (not internal ft). When the unit toggles, all inputs are recomputed from the stored ft values.
- Do not run `pnpm dev` at workspace root — use workflow restart instead.
